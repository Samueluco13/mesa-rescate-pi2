# Rescate de Alimentos
<img width="1600" height="824" alt="image" src="https://github.com/user-attachments/assets/dc8f4891-da4b-41fd-8cff-b76423e627aa" />

La solución propuesta consiste en una plataforma No-Code/Low-Code que permite gestionar el flujo de información y las interacciones con los actores del proyecto mediante herramientas visuales, reduciendo la necesidad de desarrollo de software tradicional. La integración con la API oficial de WhatsApp Business forma parte de la alternativa de referencia y requiere validación técnica y operativa.

## Qué hace

Rescate de Alimentos coordina a comercios donantes, voluntarios y organizaciones receptoras. El núcleo previsto permite registrar donaciones, consultar disponibilidad, reservar una donación de forma exclusiva, registrar su entrega y consultar su estado.

La mensajería automática, los indicadores, las exportaciones y la asignación automática de destinos se gestionan como ampliaciones del producto y requieren priorización del Product Owner.

## Estado y entorno

El proyecto se encuentra en especificación y planificación. Esta versión contiene documentación y un backlog; no acredita una aplicación implementada ni desplegada. La selección concreta de plataforma y la URL del entorno deben quedar aprobadas y verificadas en el plan técnico.

1. Revisar la especificación y los acuerdos de trabajo.

3. Validar un entorno mínimo con otro integrante y publicar aquí las instrucciones reproducibles.
4. Comprometer en un sprint únicamente actividades que cumplan DoR.
